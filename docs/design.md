# Design system: Daylight

Primitives taken from four reference pages (Ardent, Nexis, River, Respan). **Grey does the work.
Blue says where you are. Yellow marks what matters.** Tokens live at the top of
`public/css/style.css`: change the token, not the component.

## Brand

- **|M|:** the name written as a modulus. An ink M on a torn swatch of the brand yellow (#f5c518)
  between two thin ink bars. Paths only, never text.
- **Files:** `mark.svg` (bare, navbar and footer), `favicon.svg` (on a light paper tile: tabs,
  icons, login), `icon-maskable.svg` (full bleed, mark at 78%), `og-card.svg` (share card).
  Rasters: `scripts/build-brand.mjs`.
- **Highlighter (`.hl`):** the page torn open over yellow. The yellow is cut to the tear by a mask,
  so the real page shows around it. Generated by `scripts/build-highlighter.mjs` into
  `public/img/hl/` plus a marked block in style.css; edit the script, never the output.

## Rules

1. **Paper, then light.** One off-white sheet (`--canvas`), edge to edge, no frame or radius.
2. **Two inks.** Page titles run on into a grey subtitle (`--grey`, display sizes only).
3. **One saturated thing per view:** one highlight, one sky stage, or one glossy button.
4. **Pills for moving, squares for things.** Nav, buttons, search and toasts are round; set
   letters and chips have 7px corners.
5. **What matters floats.** The pinned post and current syllabus or timetable image sit in a white
   pane, ringed by a frosted bezel, on the sky gradient. All else lies flat, split by hairlines.
6. **No box inside a box,** except that bezel.

## Colour

- **Inks:** `--text-strong` titles, `--text-body` reading, `--text` secondary, `--text-muted` meta
  (AA on the sheet), `--text-faint` inactive and fine print only.
- **Blue:** the current category, eyebrow glyphs, "New", nav dots, focus rings, links.
- **Yellow:** the exam date only (the phase test date and the exam days in the week grid). The
  subscribed bell uses its soft tint.
- **Status:** green for success, red for errors and delete.
- **Light only** for now; dark mode is not drawn.

## Type

- Inter (text and display), Geist Mono (dates, numbers, set letters). OFL, self-hosted in
  `public/fonts/`. Display type is Inter tracked about 0.02em tighter, which stands in for Inter Tight
  at half the download.
- **Dark:** the tokens are redefined under `prefers-color-scheme: dark`; components use tokens, so
  only the token block and the footer word carry dark rules.
- **No swap jumps:** Inter is preloaded, and each font has a size-matched local stand-in
  (`Inter Fallback` and friends). If a font changes, re-measure the ratios with canvas
  `measureText` and update the overrides.

## Components

- **Navbar:** brand, centred section pills (current is a filled pill that slides between pages),
  alerts as an outline pill. Phones: one scrolling row, a 44px bell fixed right.
- **Layout:** `[side] head/body [rail]`. Pages with search or filters get the side column (search,
  then the River-style category index). Under 760px it becomes a row.
- **Feed:** a changelog with a mono date gutter and a hairline spine with a node per post (blue
  when new). Author initials in the meta line. "Updated <day>" eyebrow over each page title.
- **This week rail:** one grey card. The lead is the next phase test as a countdown with a week
  grid (today ringed blue, the days left counted out, the exam day highlighted).
- **Footer:** the mark beside a two-ink line, the existing links as pills (install is the glossy
  one), fine print, and the name set huge and faint at the bottom edge.

## Motion

At most 260ms, transform, opacity or clip-path only, never looping, off under reduced motion. Page
changes fade and rise under a still navbar; first cards rise in; the week grid lands cell by cell;
the exam date is stroked in; images fade in on load; presses scale to 0.98. `scrollbar-gutter:
stable` stops sideways jumps while a page loads.

## Shipping changes

- Edit `style.css` and `admin.css` (admin and login only), then run `npm run build:css` to write
  the minified files the pages load.
- Assets are cached as immutable, so bump `?v=` in `scripts/build-pages.mjs` (then run it with
  `public` as the argument), `admin.html`, `login.html`, `sw.js` (`VERSION` and precache), the
  manifest, `install.js`, and the tests that pin it.
- Current version: 12.2.
